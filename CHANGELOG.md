# Changelog

## v1.0.0 — Initial Release

### Features
- Full offline-first scheduling with local SQLite storage
- Timeline day view with 24 hour grid
- Static and dynamic time blocks
- Task pool with categories and reusable tasks
- Project management with task grouping
- Assign, reassign, and unassign tasks to dynamic blocks
- Settings — accent colour customisation and day window
- Responsive layout — Android and Windows desktop
- Optional cloud sync coming in v2
